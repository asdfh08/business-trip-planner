# business-trip-planner
# Сервис планирования командировок
Консольное приложение для учёта сотрудников и планирования их
служебных командировок: маршруты, сроки, расходы и проверка
соответствия расходов установленному бюджету.

## Назначение
Приложение помогает сотрудникам компании планировать служебные командировки: фиксировать маршрут поездки, сроки, контролировать расходы и проверять их соответствие установленному бюджету.

## Целевая аудитория
Сотрудники организаций, которые оформляют служебные командировки, а также руководители и сотрудники HR/бухгалтерии, контролирующие расходы на поездки.

## Предметная область
Учёт и планирование служебных командировок сотрудников компании: маршруты поездок, сроки, сопутствующие расходы (проезд, проживание, суточные) и их сверка с выделенным бюджетом.

## Основные сущности
- Сотрудник
- Командировка (поездка)
- Маршрут
- Расходы

## Основные функции
- Расчёт продолжительности командировки по датам начала и окончания
- Проверка расходов на соответствие установленному бюджету командировки
- Формирование краткой сводки по командировке сотрудника

## Возможности (по итогам ПР2)
- добавление и поиск сотрудников;
- добавление командировок с проверкой занятости сотрудника на даты;
- отмена командировок;
- внесение фактических расходов и проверка их соответствия бюджету;
- вывод списка командировок, отсортированного по дате начала;
- статистика по количеству и суммарным расходам командировок;
- сохранение и загрузка данных из JSON-файлов между запусками;
- обработка некорректного ввода и ошибок файлов данных.

## Формат хранения данных
Сотрудники и командировки хранятся в файлах `data/employees.json` и
`data/trips.json` в виде списка словарей. Даты хранятся в формате
`ГГГГ-ММ-ДД` и преобразуются в объекты `date` при загрузке.
